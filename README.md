# Md. Asad Iqbal — Personal Website

A responsive, static professional portfolio website prepared for free static hosting.

## Files
- `index.html` — complete website (CSS and SEO metadata included)

## Important before publishing
1. Replace the LinkedIn placeholder (`href="#"`) with your real public LinkedIn URL.
2. The email button currently uses `contact@asadiqbal.com`; do not publish it until you have configured that mailbox, or replace it with your preferred public email.
3. Confirm that your job title, employer, education and training details are accurate and that you are comfortable publishing them.
4. The canonical URL and structured data currently use `https://asadiqbal.com/`. If you publish first on a free subdomain, update these values to the actual URL until the custom domain is connected.

## Free hosting options
- GitHub Pages: free hosting for static sites, with a free `username.github.io` address. A custom domain such as `asadiqbal.com` can be connected after you register/own it.
- Cloudflare Pages: free tier for static sites, with a free `pages.dev` address. A custom domain can be connected after you register/own it.

## Domain note
`asadiqbal.com` is a paid domain name in the normal case. Hosting can be free, but owning the custom `.com` domain generally requires an annual registration fee. Domain availability must be checked with a registrar before purchase.

## SEO setup after publishing
1. Verify the website in Google Search Console.
2. Submit `https://YOUR-DOMAIN/sitemap.xml` after adding a sitemap.
3. Request indexing of the homepage.
4. Add the same name and consistent profile details to public professional profiles.
5. Do not expect instant first-place ranking or a guaranteed Knowledge Panel.
